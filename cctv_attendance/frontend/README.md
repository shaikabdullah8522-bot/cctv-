# CCTV Automated Attendance Frontend

The frontend is a modern React + TypeScript + Tailwind CSS application featuring:
1. **Live CCTV AI Recognition Monitor**: Real-time bounding box detection, student face identification against enrolled 128-d vectors, and multi-frame observation confirmation.
2. **Student Directory & Photo Enrollment**: Administrator studio for uploading student portrait photos and extracting biometric vectors.
3. **Period Timetable Schedule Manager**: Configure class period start/end hours and active tracking slots.
4. **Attendance Reports & CSV Exporting**: Multi-filter attendance queries by date, period, and status, with full audit trail logging.
5. **Student Personal Portal**: Calendar-based attendance inspection with low-attendance warnings and period logs.
