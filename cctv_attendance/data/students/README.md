# Student Enrollment Photos Directory

This directory stores uploaded student portrait photographs for biometric face identification.
Images should be named after the student's roll number or ID (e.g. `CS2026001.jpg`, `CS2026002.png`).

### Guidelines for High-Accuracy CCTV Recognition:
1. Frontal face portraits with clear facial features.
2. Even indoor illumination without strong backlight.
3. Neutral or natural expressions.
4. Minimal occlusion (avoid large sunglasses or masks).
